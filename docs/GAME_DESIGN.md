# 《候選人！》GAME DESIGN — Alpha 0.42

## 設計目標

這是一款以「虛構政治候選人參選」為題材的風險報酬型競選策略遊戲。

核心不是精準模擬真實政治，而是讓玩家在遊戲過程自然感受到：

- 聲量不等於支持度。
- 地方組織需要時間累積。
- 政策專長會受當前議題影響。
- 負面攻擊可能有效，也可能反噬。
- 資金是策略放大器，不直接等於勝利。
- 社會議題改變後，原本最佳策略可能失效。
- 角色有專長，但不限制玩家只能走特定路線。

預設全部使用虛構候選人、虛構政黨背景，不加入真實政治人物。

## 核心循環

每輪：

1. 擲 D6。
2. 沿目前選定路線移動。
3. 處理重大時間軸事件；一般路線格只有「停下來」才取得完整效果。
4. 玩家取得 3 AP（特殊節點可能增加）。
5. 執行空軍 / 陸軍 / 政策 / 攻擊行動。
6. AI 完成其回合。
7. 第一位到達投票日後進入最後一輪，再結算勝負。

## 主要資源

- `support` 支持度：最直接的勝利基礎。
- `funds` 資金：支付廣告與部分行動。
- `media` 聲量：曝光，採邊際遞減。
- `org` 組織力：地方與投票動員，採邊際遞減。
- `trust` 信任度：政策與正面競選的重要資源，採邊際遞減。
- `controversy` 爭議值：過高會帶來反噬與結算懲罰。

## 四類競選策略

### 空軍 `air`
媒體、廣告、直播、社群。

主要取得聲量，部分行動轉成支持度。

### 陸軍 `ground`
掃街、座談、志工、地方組織。

主要取得組織力、信任與少量支持。

### 政策 `policy`
政見、記者會、辯論。

受到候選人議題專長與當前社會議題影響。

### 攻擊 `attack`
政策質疑、負面攻勢、匿名爆料。

可以削弱對手，但提高爭議與反噬風險。

## 策略疲勞

同類策略連續使用，效果遞減：

- 第 1～2 次：約 100%
- 第 3 次：約 78%
- 第 4 次：約 60%
- 第 5 次：約 46%
- 之後：約 34%

目的：避免單一最佳策略無限連發。

## 六名 Alpha 角色

### 林阿城 — 地方老將
強項：陸軍、組織動員。
玩法：地方組織逐步轉為後期支持。

### 許文哲 — 政策學者
強項：政策、辯論、教育。
玩法：政策失敗具有有限重骰能力。

### 夏薇 — 媒體明星
強項：空軍、聲量。
玩法：高曝光、高爭議、高波動。

### 江一新 — 改革素人
強項：混合策略。
玩法：低爭議時切換策略有額外收益。

### 高富民 — 企業經理人
強項：資金、付費廣告。
玩法：更有效率地把資金轉成曝光與支持。

### 蘇暖暖 — 草根倡議者
強項：陸軍、信任、社福。
玩法：穩定累積地方連結與動員。

## 棋盤

共 48 節點，包含五次主要二選一分岔：

1. 空軍 / 陸軍
2. 政策 / 募款
3. 正面競選 / 負面攻擊
4. 辯論媒體 / 地方深耕
5. 最後空戰 / 投票動員

因此宏觀路線共有 `2^5 = 32` 種。

重要規則：

- 一般路線格只有停下來才取得完整收益。
- 重大時間軸節點即使被骰子跨過仍會觸發。
- 第一位抵達終點不直接勝利。

## 重大社會議題

目前：

- 居住與生活成本
- 薪資與就業
- 少子化與托育
- 高齡與長照
- 交通安全
- 詐騙與數位安全
- 能源與環境

### 議題共鳴

重大議題會改變四類策略的收益與攻擊風險。

介面應直接提示：

- 哪些策略有共鳴。
- 實際倍率。
- 哪些攻擊反噬風險提高。

Alpha 0.42 的單一共鳴倍率上限為 **×1.50**。

## 勝負

第一位抵達投票日後，所有玩家完成最後一輪。

目前結算概念：

`支持度 + 聲量遞減加成 + 組織遞減加成 + 信任遞減加成 + 動員 + 當前議題優勢 - 爭議懲罰 + D6`

未來可調整，但不要讓任何單一資源直接線性碾壓。

## 平衡原則

1. 不追求每名候選人精確 16.67%。
2. 理想上角色有擅長玩法，但逆向玩法仍可行。
3. 路線的期望收益接近，但風險分布不同。
4. 高報酬策略必須有成本、風險或時間代價。
5. UI 必須揭露會改變玩家決策的主要倍率，避免隱藏規則。

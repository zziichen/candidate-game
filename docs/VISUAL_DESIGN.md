# 街頭選戰版：視覺與介面

## 方向

虛構臺灣街區 × 插畫桌遊。以紙張、招牌、街角商店與候選人棋子建立親切的競選桌遊感；不用真實人物、政黨或選舉背景。

- 暖紙底色 `#f5f0e5` 與卡片 `#fffdf7`。
- 深藍墨色 `#192d35` 用於標題、招牌與操作列。
- 朱紅 `#d75036` 用於主要操作與玩家位置。
- 空軍藍、陸軍綠、政策金、攻擊紅作為路線與行動分類色，並同時保留文字和圖示，避免只依顏色辨識。
- 使用裝置內建繁體中文字型，無外部字型或圖庫依賴。人物先使用原有配色的姓名棋子，完整人物美術另行製作。

## 地圖與流程

48 節點、52 連線、五次主要分岔全部由原本 `nodes` 與 `gateAt` 驗證。`visuals.js` 只定義座標、顏色與階段瀏覽標籤，不能參與步數、收益或結算。

SVG 繪製道路、箭頭與街角店面；HTML 顯示節點文字、玩家棋子及位置。不同長度的路線如實顯示，遊戲仍使用原有棋盤拓樸。

- 五個階段按鈕只捲動地圖，不改變路線選擇。
- 我的位置按鈕定位人類玩家；玩家移動後，地圖自動跟隨。一般行動或 AI 行動保留玩家手動瀏覽位置。
- 玩家位置、下一站、已選分岔道路與重大事件可分辨。
- 固定底部操作列依序提示擲骰、行動、結束回合；競選行動按鈕可跳到行動區。
- 資源、能力、議題共鳴與反噬、支持度排名、事件紀錄均保留。支持度排名不宣稱是最終得票。
- 手機提供完整文字節點、垂直可捲動地圖、雙欄行動、底部安全區；320px 路線選擇改為單欄。
- 加入鍵盤可操作的選角、地圖導航、說明對話框與路線 modal；路線與結果視窗有焦點管理，尊重 reduced-motion 設定。

## 程式邊界與驗證

呈現函式移至 `ui.js`，以免把新增地圖繪製與樣式塞回 `game.js`。規則、資料、AI、狀態、亂數與回合協調保持原樣；`finishGame` 的既有結算和輸出仍保留。

來源檢查仍逐宣告比對非 UI 程式與 legacy。固定種子完整遊戲比對所有遊戲狀態、事件、議題及行動提示語意與結果；不再要求已重新設計的 HTML/CSS 與 legacy 相同。

`tests/layout.cjs` 驗證 1440、1024、768、390、320px 的橫向溢出、地圖拓樸、階段／位置導航、說明視窗、鍵盤選路、實際行動與操作列遮擋。可用 `SMOKE_SCREENSHOT_DIR` 產生桌面與手機 QA 截圖；`SMOKE_SITE_URL` 可改為已部署網址以檢查正式站。
